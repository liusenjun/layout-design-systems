在两种语言之间阅读Reading Between Languages

一份用于展示中文主阅读、英文原文核对与连续双语阅读的通用长文模板。

说明：替换占位内容时，保留原文顺序、双语语义配对与来源信息。
怎样查看英文原文将鼠标移到中文段落上，英文会在右侧浮现；点击可固定，再次点击或按 Esc 关闭。手机上点击段落即可在下方展开。

好的双语页面不应迫使读者同时处理两列正文。它应先提供一条清晰的主阅读路径，再在需要核对时让另一种语言自然出现。

A good bilingual page should not force readers to process two permanent columns. It should offer one clear reading path first, then reveal the other language naturally when verification is useful.

这个模板默认以中文为主。桌面端悬浮只显示左侧橙色标记和右侧英文；点击后才固定对照并为当前中文语义组增加淡色背景。

This template defaults to Chinese. On desktop, hovering shows only the orange marker and the English source on the right; clicking pins the comparison and adds a pale background to the current Chinese semantic group.

模板必须保存经过真实项目验证的页面骨架，而不是只保存一组看起来相似的样式。

A template must preserve the page skeleton validated by a real project, not merely a collection of styles that looks similar.

语义结构先于视觉包装Semantic Structure Before Decoration

每个可独立阅读的内容单元使用一个双语语义组。中文和英文表达相同范围的观点，但不要求逐句机械对应。

Each independently readable unit uses one bilingual semantic group. Chinese and English cover the same idea, but they do not need to mirror each sentence mechanically.

整理内容时，应当同时检查：

  • 标题层级是否反映论述结构；
  • 列表是否与引导它的句子保持在同一语义组；
  • 两种语言是否存在没有对应内容的观点。

When preparing the content, check:

  • whether heading levels reflect the argument;
  • whether a list stays with the sentence that introduces it;
  • whether either language contains an unmatched claim.

在中英混排模式中，英文原文位于上方，中文译文位于下方。两种语言依靠字体区分，而不是通过缩小字号或增加盒子制造层级。

In bilingual mode, the English source appears above the Chinese translation. The languages are distinguished by typeface, not by shrinking one language or placing every paragraph in a box.

让组件承担明确职责Give Components Clear Jobs

普通段落保持连续阅读。只有真正决定后续理解的框架或判断，才进入深色 Key Statement。

Ordinary paragraphs remain part of the continuous reading flow. Only a framework or judgment that determines what follows belongs in a dark Key Statement.

操作型文本Actionable Text

“请先列出这项任务中最可能改变架构的三个未知，并一次只向我确认一个问题。”

“List the three unknowns most likely to change the architecture, then ask me to resolve them one question at a time.”

“在修改真实应用之前，先用单文件 HTML 制作一个可点击原型，让我能够对布局做出反馈。”

“Before changing the real application, build a clickable single-file HTML prototype so I can react to the layout.”

Action Text Card 的边框、标签、引号和正文区域在三种模式中保持稳定。悬浮只增加左侧橙色块，不改变背景或文字颜色。

The Action Text Card keeps its border, labels, quotation mark, and content area stable in all three modes. Hover adds only the orange bar and never changes its background or text color.

组件的视觉强度必须与语义强度相匹配。

The visual intensity of a component must match its semantic intensity.

图片仍然属于文章顺序Images Remain Part of the Article

图片应当出现在它所支持的论述附近。中文模式显示中文图注，英文模式显示英文图注，中英混排依次显示英文和中文图注。

Images should appear near the argument they support. Chinese mode shows the Chinese caption, English mode shows the English caption, and bilingual mode presents English followed by Chinese.

替换示例图片时，应使用相对路径，并确保 HTML 与资源文件夹可以一起移动。不要为了填满页面而加入与论点无关的装饰图。

When replacing the example images, use relative paths so the HTML and asset folder remain portable together. Do not add decorative images merely to fill the page.

交付前检查三条阅读路径Verify All Three Reading Paths

中文模式应提供安静的主阅读流和按需英文核对；中英混排应保持英文在上、中文在下；英文模式应完整镜像中文模式的交互。

Chinese mode should provide a quiet primary flow with English on demand; bilingual mode should keep English above Chinese; English mode should fully mirror the interaction of Chinese mode.

最后检查桌面宽度、紧凑目录、移动端点击、键盘操作、打印输出和资源路径，再将模板内容替换为真实文章。

Finally, verify desktop width, compact navigation, mobile tapping, keyboard behavior, print output, and asset paths before replacing the template content with the real article.

模板提示：本页的长度和组件组合用于展示真实长文节奏。生成新文章时，可以删除不需要的组件，但不要改变三种阅读模式的基础结构。
