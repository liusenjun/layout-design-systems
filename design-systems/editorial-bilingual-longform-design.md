# Editorial Bilingual Longform Design System

Version: 1.1
Status: validated
System ID: `editorial-bilingual-longform`
Parent system: `editorial-longform`

## 1. 系统定位

这是一套由真实英文长文项目验证过的双语编辑阅读系统。它把已经完成内容编辑的英文文章制作成可连续阅读的独立 HTML。默认帮助中文读者顺畅阅读，同时允许在当前段落旁核对英文原文；也为英文优先读者提供镜像的中文对照。

最终输出始终是文章式 HTML。英文文章直接进入排版，不进行实质改写；音频、视频和逐字稿只是上游素材，必须先被忠实重构为结构完整的文章。可以保留时间戳作为来源元信息，但默认不嵌入播放器，也不提供播放器同步、逐段 seek、实时字幕高亮或媒体应用界面；只有用户明确要求时，才把播放器作为独立扩展。

适用：

- 有完整英文来源、需要忠实中文翻译的长文章；
- 已由上游流程从访谈、播客、演讲或视频重构完成的英文文章；
- 需要中文主阅读、英文原文核对和连续双语阅读三种路径；
- 需要保留原图、画面截图或图注顺序的资料。

不适用：

- 只有摘要、不需要原文对应关系的内容；
- 逐词学习器、字幕播放器、语言测试产品；
- 需要事实补充、评论扩写或观点重构的编辑任务；
- 短营销页、幻灯片、后台或交易界面。

## 2. 继承与覆盖

默认继承 `editorial-longform` 的颜色、H1/H2/H3 基础尺寸、18px / 1.78 正文基准、无独立导语字号、图片、表格、打印和无障碍规则。

本系统只覆盖双语阅读所需部分：

- 三种阅读模式；
- 中英字体分工与顺序；
- 语义组间距；
- 右侧对照栏；
- 双语标题、图注、Key Statement 和 Action Text Card；
- 中等宽度下的紧凑目录。

## 3. 内容准备

先执行 `../references/english-source-to-bilingual-html.md`。每个可独立理解的英文语义块必须与一个中文语义块配对，结构统一为：

```html
<div class="bi">
  <div class="zh">…忠实中文…</div>
  <div class="en" lang="en">…英文原文…</div>
</div>
```

不要为了视觉整齐逐句机械切分。一个语义组可以包含多个自然段或列表，但中英文应表达相同范围的内容。

## 4. 三种阅读模式

### 中文模式（默认）

- 页面只在主栏显示中文；
- 鼠标悬浮或键盘聚焦时，仅在段落左侧显示橙色色块；
- 对应英文出现在右侧对照栏，顶部与当前语义块的外边界对齐；
- 点击可固定当前对照，固定时中文语义块才增加淡橙背景；
- Key Statement 和 Action Text Card 的背景、边框、文字色在 Hover 时保持不变。

### 中英混排模式

- 英文在上，中文在下；原文拥有第一阅读顺序；
- 同一语义组内的中英间距为 `10px`；
- 相邻语义组之间的间距为 `30px`；
- 不增加缩进、引导线、英文盒子、悬浮、点击或固定状态；
- 英文与中文正文均为 18px / 1.78，靠字体而非字号区分语言。

### 英文模式

- 页面只在主栏显示英文；
- 交互与中文模式镜像：悬浮或固定时，右侧对照栏显示中文；
- 英文正文不使用段落底线或单独卡片；
- Key Statement 与 Action Text Card 保留完整组件骨架。

模式切换必须位于文章顶部，使用按钮并维护 `aria-pressed`。切换模式时清除已固定段落。

## 5. 字体与字号

- 中文使用系统无衬线：`-apple-system, BlinkMacSystemFont, "Segoe UI", "PingFang SC", "Hiragino Sans GB", "Microsoft YaHei", sans-serif`。
- 英文使用衬线：`Georgia, "Times New Roman", serif`。
- 中文和英文普通正文：18px / 1.78。
- 导语不建立独立字号；可保留 `.lead` 作为语义类。
- Key Statement：中文 19px，英文 18px。
- Metadata、目录、标签与图注：12–13px。

### 双语标题

所有双语标题优先在同一行自然衔接，空间不足时让次级语言整体换到下一行。

#### H1 主标题

- 中文模式：中文主标题在前，英文作为 62% 的次级标题。
- 中英混排模式：英文主标题在前，中文作为 70% 的次级标题。
- 英文模式：只显示英文主标题。

#### H2 / H3

- 中文模式：中文在前；H2 英文为中文的 `74%`，H3 英文为中文的 `82%`，使用次要文字色和 500 字重。
- 中英混排模式：英文在前且使用基础标题的 100%、主文字色、700；H2 中文为英文的 `82%`，H3 中文为英文的 `88%`，使用次要文字色和 500 字重。
- 英文模式只显示英文标题。

## 6. 布局

大桌面使用四个概念区：250px 目录、820px 正文、52px 间距、360px 右侧对照栏。页面最大宽度约 1600px。

右侧对照栏只在需要时出现，不是额外正文列。具体横向偏移：普通语义组为 `52px`，Key Statement 为 `66px`，Action Text Card 为 `67px`；三者最终浮层左边缘必须一致。特殊组件的浮层使用 `top: 0` 与组件外框顶部对齐，不按内部文字基线对齐。

1181–1500px：目录收为左侧窄入口，默认 38px × 82px；Hover、Focus 或点击固定时展开至约 238px，最大高度 420px。动画使用 280ms `cubic-bezier(.22,1,.36,1)`，内容延迟约 90ms 淡入。点击固定后不得因鼠标移出而缩回。双语布局需要同时为 820px 正文和 360px 对照栏留出空间，所以这里有意覆盖基础系统在 ≥1180px 保留完整目录的规则。

851–1180px：保留侧栏和主栏，翻译在当前段落下方展开。850px 以下改为单栏，Hover 不作为唯一入口，点击或键盘操作展开对照。

## 7. 组件

### 普通语义组

单语模式下，块自身上下各 6px，使段落节奏约为 12px，同时保留完整的交互热区。Hover 只出现左侧橙色色块；固定时才显示淡色背景。

### Key Statement

三种模式统一使用深色背景、白字和左侧 `7px` 橙色色块。Hover 不反转背景或文字色。它只承载决定性框架、关键判断或关键问题。

### Action Text Card

用于可复制或可执行的提示词、命令、查询与示例。三种模式统一保留：

- 完整 1px 灰色边框和浅卡片背景；
- 左上角橙色大引号；
- 左上可变语义标签；
- 右上可变英文类型标签，例如 `PROMPT`；
- 18px / 1.78 正文；
- 默认骨架稳定；在双语的中文或英文单语模式中，Hover、Focus 或固定时只叠加左侧 `5px` 橙色色块。

`PROMPT` 是当前类型装饰，不是固定文案。遇到命令、查询、脚本或其他操作型文本时，替换为相应类型。

### 图片与双语图注

原始图片或从音视频中选取的解释性画面必须按来源顺序放回对应论述附近。中文模式显示中文图注，英文模式显示英文图注，中英混排模式依次显示英文、中文图注。图注必须忠实说明画面与当前论点的关系，不凭空补充来源中没有的信息。

## 8. 交互与无障碍

- 只有中文模式和英文模式具有段落 Hover、Focus 和固定交互；
- 中英混排模式移除 `role="button"`、`tabindex` 与 `aria-expanded`；
- 单语模式的语义块可由 Enter / Space 固定，由 Escape 关闭；
- 固定后的对照栏必须显示简短状态说明，提示点击当前主语言内容或按 Escape 关闭；
- 任何信息不得只能依赖 Hover 获得；
- 尊重 `prefers-reduced-motion`；
- 焦点提示、橙色色块与文字标签共同表达状态，不只依赖颜色。

## 9. 打印

打印时隐藏侧栏、模式切换和右侧浮层；按英文在上、中文在下输出全部语义组。Key Statement、Action Text Card、图片和表格尽量不跨页断开。

## 10. 禁止事项

- 不把双语正文做成桌面永久双栏；
- 不给每段英文加盒子、底线、标签或缩进；
- 不用更小字号制造语言层级；
- 不让 Hover 改变深色块或提示词卡片的底色和文字色；
- 不用自动翻译结果替代语义核对；
- 不制作同步播放器，也不把时间戳误当作交互时间轴；
- 不把真实项目的文章标题、作者、段落数、图片数或组件数写入模板。
