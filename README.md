# Layout Design Systems

A personal, extensible Codex skill for selecting and applying reusable visual layout systems to finished content.

The first included system is **Editorial Longform**: a clean, editorial-style HTML layout for course notes, video or podcast summaries, deep articles, methods, and knowledge documents.

## Included design systems

| System | Best for | Output |
|---|---|---|
| Editorial Longform | Long-form reading, learning notes, summaries, and thoughtful sharing | Standalone HTML webpage |

## Install

Clone the repository into your personal Codex skills directory:

```bash
git clone https://github.com/liusenjun/layout-design-systems.git ~/.codex/skills/layout-design-systems
```

If the directory already exists, clone elsewhere and copy or update the files intentionally.

## Use

```text
Use $layout-design-systems to recommend and apply a suitable layout design system to my finished content.
```

To choose the current system directly:

```text
Use $layout-design-systems and apply Editorial Longform to create a readable standalone webpage.
```

This skill handles visual presentation only. Content extraction, research, fact-checking, and summarization should be completed before applying a layout system.
